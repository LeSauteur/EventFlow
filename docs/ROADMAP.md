## Этот PR

Единый вычисляемый реестр, «Сегодня», календарь, независимые важность/срочность/
ручное «Горит», ожидания, метки, сохранённые фильтры, закрепление мероприятий.
Одна коллекция `floodEntries`, доступная из «Сегодня», меню и мероприятия.
Идентификатор записи стабилен, eventId необязателен, состояния: новое,
разобрано, архив, корзина. Каждая вставка — самостоятельная запись; редактирование
с автосохранением. Копирование, привязка/отвязка, поиск, фильтры, мягкое удаление,
восстановление и массовая очистка с подтверждением. Не добавлять Флуд в timeline.
Синхронизация через существующий GitHub по последнему уточнению владельца.

Выделение фрагмента и ручное создание задачи реализованы с явным подтверждением.
