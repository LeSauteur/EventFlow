Открыть инструкцию со скриншотами

Перед работой

Проверьте подключение GitHub token на каждом устройстве. После изменений нажмите «Сохранить в GitHub» и дождитесь зелёного статуса с последним временем. Затем можно продолжать с телефона или компьютера.

В инструкции 11 страниц. Скриншоты показывают опубликованный интерфейс на учебных данных; рабочие записи и настоящие токены в них не используются.
